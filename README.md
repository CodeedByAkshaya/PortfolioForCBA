🚀 Run Locally

1. Clone the repository

git clone https://github.com/CodeedByAkshaya/PortfolioForCBA.git

2. Open the project

cd PortfolioForCBA

3. Launch the portfolio

Open index.html directly in your browser.

For a better development experience, you can also use the Live Server extension in VS Code.

🌐 Deploy with GitHub Pages

You can publish this portfolio for free using GitHub Pages:

Open the repository on GitHub.

Go to Settings → Pages.

Under Build and deployment, choose Deploy from a branch.

Select the main branch.

Select / (root).

Save the settings.

GitHub will generate a public URL once Pages is enabled.
