## ✨ About

This is a modern, playful and responsive personal portfolio created for **Akshaya**.

The website combines a clean portfolio layout with a fun **Pikachu-inspired spark theme**, animations and interactive elements.

The main idea behind the portfolio is:

> **Small spark. Big possibilities.**

The portfolio represents curiosity, learning, creativity and the journey toward becoming a Computer Engineer.

---

## ⚡ Features

- Modern and creative UI
- Pikachu-inspired design theme
- Fully responsive layout
- Smooth scrolling
- Scroll animations
- Interactive project cards
- Animated elements
- Mobile-friendly navigation
- Clean typography
- Keyboard accessibility
- Reduced-motion support
- No framework required
- No build process required
